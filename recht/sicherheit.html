Sicherheit melden

Haben Sie eine Sicherheitslücke in Kontovia gefunden? Bitte melden Sie sie so, dass wir sie beheben können, bevor andere sie ausnutzen. Die englische Fassung steht weiter unten (English version below).

So melden Sie

  • Schreiben Sie an platzhalter@example.org, Betreff „Sicherheit“.
  • Nennen Sie, was Ihnen aufgefallen ist, wie wir es nachstellen können, die Programmversion (unter Hilfe, Rechtliches) und Ihren Browser.
  • Schicken Sie bitte keine echten Buchhaltungsdaten, Passwörter oder Schlüssel mit. Eine Nachbildung genügt.
  • Sie können deutsch oder englisch schreiben.

Was wir tun

  • Wir lesen jede Meldung und bestätigen den Eingang so bald wir können.
  • Wir prüfen sie, melden uns mit dem Ergebnis und halten Sie auf dem Laufenden, wenn es länger dauert.
  • Bitte veröffentlichen Sie Einzelheiten erst, wenn eine behobene Fassung bereitsteht oder wir uns über den Zeitpunkt verständigt haben.

Behebung und Aktualisierungen

Wir stellen Behebungen bekannt gewordener Sicherheitslücken, soweit uns das möglich und zumutbar ist, so bald wie möglich als neue Fassung bereit. Aktualisiert wird nur nach Ihrer Bestätigung. Auf sicherheitsrelevante Änderungen weisen wir in den Versionshinweisen hin, sobald das ohne Gefahr für andere Nutzerinnen und Nutzer möglich ist. Eine bestimmte Frist und eine bestimmte Dauer der Unterstützung sagen wir damit nicht zu.

Was in Kontovia steckt

Welche fremden Bestandteile Kontovia enthält (Datenbank, Texterkennung, Assistent, Schrift) und in welcher Fassung, steht in einer Software-Stückliste im Format CycloneDX: sbom.json auf der Webseite von Kontovia. Die Sprachmodelle des Assistenten gehören nicht zur Auslieferung, Sie laden sie selbst herunter; sie stehen dort als „vom Nutzer geladen“. Den Sicherheitskontakt in maschinenlesbarer Form finden Sie in security.txt.

Report a security vulnerability

Have you found a security vulnerability in Kontovia? Please report it so that we can fix it before others exploit it.

  • Write to platzhalter@example.org with the subject "Security".
  • Tell us what you noticed, how we can reproduce it, the program version (under Help, Legal) and your browser.
  • Please do not send real accounting data, passwords or keys. A replica is enough.
  • You can write in German or English.

What we do

  • We read every report and confirm receipt as soon as we can.
  • We assess it, get back to you with the result and keep you informed if it takes longer.
  • Please publish details only once a fixed version is available or we have agreed on a date.

Fixes and updates

Where possible and reasonable, we provide fixes for security vulnerabilities that become known as a new version as soon as we can. Updates are installed only after you confirm. We point out security-relevant changes in the release notes as soon as that is possible without putting other users at risk. We do not commit to a specific deadline or a specific period of support.

What is inside Kontovia

Which third-party components Kontovia contains (database, text recognition, assistant, font) and in which version is listed in a software bill of materials in CycloneDX format: sbom.json on the Kontovia website. The assistant's language models are not part of the delivery, you download them yourself; they are marked there as "loaded by the user". The security contact in machine-readable form is in security.txt.
